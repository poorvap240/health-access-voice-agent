# Health Access Voice Agent 🎙️

A voice-based AI assistant that makes health information easier to access through natural conversation. Built for the **#VoiceForBharat "10 Days of Voice Agents"** challenge (Health Access track).

## Features
- Talk to the agent by voice instead of typing
- Natural Indian English voice (Murf, voice: Anisha)
- Real-time, low-latency voice conversation

## Tech Stack
- TypeScript
- LiveKit Agents (real-time voice)
- Murf AI (text-to-speech)

## Getting Started

### Prerequisites
- Node.js 18+
- LiveKit and Murf API keys

### Setup
1. Clone the repo
   `git clone https://github.com/poorvap240/health-access-voice-agent.git`
2. Go to the project folder
   `cd health-access-voice-agent`
3. Install dependencies
   `npm install`
4. Create a `.env` file and add your API keys
5. Run the agent
   `npm run dev`
